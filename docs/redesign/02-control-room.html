PROTOTYPE
Seen first The status lamps, then the board monitor, then SCRAP. One action The RUN key. On a finished board it becomes NEXT. Where it goes RUN inspects and shows SCRAP. NEXT clears the monitor. Errors A full-width alarm. Offline turns the lamp red. A mismatched pair stops the pass. Template fallback is a lamp, and SCRAP stays. Ask prints the SqlGuard rejection in the console.
